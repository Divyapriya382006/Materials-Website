# Material Website

## 📌 Project Overview
The **Material Website** is a static web application designed to organize and provide easy access to academic materials such as notes, books, previous year question papers, syllabus documents, and module-wise resources.

The website is structured semester-wise and subject-wise, allowing users to quickly navigate and download relevant study materials through a clean and intuitive interface.

---

## 🌐 Website Structure

### 🔹 Index Page
- Navigation bar with links to:
  - First Semester
  - Second Semester
  - Third Semester
  - Fourth Semester
- “About Me” section introducing the creator
- Central entry point to all academic resources

---

### 🔹 Semester Pages
Each semester page displays:
- A **grid layout** of all subjects offered in that semester
- Clickable subject cards for easy navigation

Example:
- Fourth Semester
  - Data Science
  - Operating Systems
  - Database Management Systems
  - Other subjects

---

### 🔹 Subject Pages
Each subject page contains:
- Subject objective / overview
- Downloadable academic resources including:
  - Reference books (displayed as images)
  - Previous year question papers
  - Syllabus PDFs
  - Module-wise PDFs

Clicking on a book image or resource image triggers a **direct PDF download**.

---

### 🔹 Module Section
- Modules are displayed as images
- Clicking a module image opens or downloads the corresponding module material
- Consistent layout followed across all subjects and semesters

---

## 🎨 Design & Layout
- Responsive grid-based layouts
- Image-based navigation for books and modules
- Clean, minimal UI focused on usability
- Consistent design across all pages

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3**

> No JavaScript, no backend, no frameworks.  
> The entire website is built using pure HTML and CSS.
